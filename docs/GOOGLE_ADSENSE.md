# Google AdSenseの登録と導入

この文書は、フォーカードをWebサイトとしてAdSenseに登録し、審査後に広告を掲載するための手順です。AdSenseはWebサイト向けのため、将来ネイティブアプリ内にリワード広告や全画面広告を出す場合は別の広告サービス・SDKとそのポリシーを確認してください。現在のアプリにはAdSense連携、独自ドメイン、プライバシーポリシーがありません。広告コードや発行者IDはアカウントごとに異なるため、このリポジトリには仮の広告コードを追加していません。

## 1. 申請前の準備

1. AdSenseの[利用条件](https://support.google.com/adsense/answer/9724?hl=ja)を確認します。申請者がサイトを管理でき、広告掲載に適した独自のコンテンツを公開している必要があります。審査通過は保証されず、ページ数や記事数だけで決まるものでもありません。
2. 独自ドメインを用意してCloudflare Workersに接続します。現在の`workers.dev` URLではなく、サイトを継続して管理できる独自ドメインを申請対象にしてください。Workersへの独自ドメイン設定は[Cloudflareのドキュメント](https://developers.cloudflare.com/workers/configuration/routing/custom-domains/)を参照してください。
3. サイトを一般公開し、HTTPSでアクセスできること、ゲームのルールや遊び方など利用者に役立つ独自の説明、問い合わせ先を整えます。現在のサイトはゲーム画面が中心で、説明ページや問い合わせ先がないため、申請前に不足する案内を用意してください。AdSenseのクローラーがページを確認できるようにし、ログイン必須やメンテナンス画面だけの状態で申請しないでください。
4. Cookieや広告配信に伴うデータ利用を説明するプライバシーポリシーを作成し、サイトから閲覧できるようにします。法令や対象地域に応じた同意取得も別途確認してください。これは法的助言ではありません。

## 2. AdSenseに登録してサイト審査を申請

1. [Google AdSense](https://www.google.com/adsense/start/)にGoogleアカウントで登録します。アカウントの国・地域、支払い先の氏名・住所などは正確に入力します。
2. AdSense管理画面の **サイト** から **新しいサイト** を選び、独自ドメインを登録します。
3. 管理画面に表示された方法でサイトの所有権を確認します。案内されたAdSenseコードを`<head>`内に置く方法を使う場合は、後述の「このリポジトリへのコード設置」を参照してください。コードやメタタグは管理画面からコピーし、第三者に共有しないでください。
4. 所有権確認後、管理画面から審査をリクエストします。審査中もサイトを公開したままにし、結果や追加対応の依頼を管理画面とメールで確認します。
5. 不承認の場合は、管理画面に示された問題を直してから再審査を申請します。審査期間や結果は状況により異なります。

## 3. 審査後に広告を設置

審査通過後、AdSense管理画面で自動広告または広告ユニットを設定し、表示されたコードを使います。所有権確認に使ったコードがそのまま広告配信コードになるとは限らないため、管理画面の案内に従ってください。

### このリポジトリへのコード設置

- このアプリの公開元HTMLは`public/index.html`です。審査用コードやサイト全体で必要なAdSenseコードを使う場合、管理画面から取得したコードを`<head>`内に追加します。ビルドはこのファイルを`dist/index.html`にコピーします。
- 広告ユニットを使う場合は、管理画面が指定する広告枠コードと表示領域をHTMLに追加します。操作ボタン、カード、ゲーム画面の操作領域に重ねたり、誤タップを誘う配置にしたりしないでください。
- このアプリは画面を切り替えるシングルページアプリです。画面を切り替えるたびに広告スクリプトを重複実行したり、広告表示を不正に再読み込みしたりしないでください。導入後は画面遷移やモバイル表示も実機で確認します。
- 広告コード内の発行者IDなどをソース管理する場合、公開サイトから閲覧可能な情報と秘密情報を区別してください。AdSenseコード自体を秘密の認証情報として扱う必要はありませんが、管理画面へのアクセス情報や支払い情報をリポジトリに保存してはいけません。

### `ads.txt`の設定

AdSense管理画面で`ads.txt`の対応を求められたら、表示された発行者IDを使った行を作成します。一般的な形式は次のとおりです。`pub-...`は実際のIDに置き換え、例のまま公開しないでください。

```text
google.com, pub-XXXXXXXXXXXXXXXX, DIRECT, f08c47fec0942fa0
```

このアプリはビルド時に`public/`内のファイルを`dist/`へ明示的にコピーします。そのため、`ads.txt`を導入するときは`public/ads.txt`を作成し、`scripts/build.mjs`の`publicFiles`にも`ads.txt`を追加してからデプロイします。公開後に`https://<独自ドメイン>/ads.txt`を開き、内容が読めることを確認してください。IDや記載内容は管理画面の指示を優先します。

## 4. プライバシー、支払い、運用

- プライバシーポリシーには、Googleなどの第三者によるCookie等の利用、広告配信・パーソナライズに関する説明と、ユーザーが設定を確認する方法を記載します。対象地域のプライバシー法と同意要件を確認し、必要な場合はGoogle認定CMPなどを設定してください。詳しくは[Googleの同意管理要件](https://support.google.com/adsense/answer/13554116?hl=ja)を確認します。
- AdSense管理画面で本人確認、税務情報、住所確認、支払い方法など、アカウントに表示される必要事項を完了します。要件と支払い条件は国・地域によって異なります。
- 広告を自分でクリックしたり、他者にクリックを頼んだりしてはいけません。広告クリックを促す文言・配置や無効なトラフィックを避け、[AdSenseプログラムポリシー](https://support.google.com/adsense/answer/48182?hl=ja)を継続して確認します。
- 公開後はAdSense管理画面の審査状況、ポリシー通知、`ads.txt`の状態、広告表示とサイト動作を定期的に確認します。広告が表示されない場合は、ドメイン、審査状況、コードの設置位置、`ads.txt`の取得可否、ブラウザーの広告ブロック設定などを確認してください。
